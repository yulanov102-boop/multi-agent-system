# 🤖 Возможности Мультиагентной Системы

## Обзор

Система автоматизирует полный цикл создания и распространения контента через 5 специализированных агентов, работающих последовательно для обеспечения высокого качества результата.

---

## 📊 Агент Исследователь (Researcher)

**Роль:** Сбор и проверка информации

### Что может делать:
- ✅ Искать актуальную информацию по теме
- ✅ Проверять источники информации
- ✅ Собирать статистику и факты
- ✅ Структурировать информацию логично
- ✅ Выделять ключевые пункты
- ✅ Организовывать данные для дальнейшей обработки

### Выходные данные:
```json
{
  "topic": "Тема исследования",
  "key_points": ["Пункт 1", "Пункт 2", ...],
  "facts": ["Факт 1", "Факт 2", ...],
  "research": "Подробное исследование",
  "structure": "Рекомендуемая структура контента"
}
```

---

## ✍️ Агент Копирайтер (Copywriter)

**Роль:** Создание привлекательного контента

### Что может делать:
- ✅ Писать заголовки, привлекающие внимание
- ✅ Создавать интригующие вводы
- ✅ Структурировать контент на разделы
- ✅ Адаптировать тон под целевую аудиторию
- ✅ Добавлять выводы и призывы к действию
- ✅ Оптимизировать для чтения и понимания
- ✅ Создавать контент для блогов и соцсетей

### Выходные данные:
```json
{
  "title": "Привлекательный заголовок",
  "intro": "Интригующее вступление",
  "sections": [
    {
      "heading": "Раздел 1",
      "content": "Содержание"
    }
  ],
  "conclusion": "Выводы",
  "cta": "Призыв к действию",
  "target_audience": "Целевая аудитория"
}
```

## 📱 Агент Telegram (TelegramAgent)

**Роль:** Адаптация контента для Telegram и отправка

### Что может делать:
- ✅ Адаптировать контент под ограничение в 4096 символов
- ✅ Форматировать сообщения в Markdown
- ✅ Добавлять emoji для визуального выделения
- ✅ Разделять большой контент на несколько сообщений
- ✅ Генерировать релевантные хештеги
- ✅ Оптимизировать для мобильного чтения
- ✅ **Отправлять сообщения в Telegram по команде**
- ✅ Отслеживать статус отправки

### Выходные данные:
```json
{
  "message_count": 1,
  "messages": [
    {
      "part": 1,
      "content": "Текст сообщения с Markdown разметкой",
      "hashtags": ["#тег1", "#тег2"],
      "message_id": 12345
    }
  ],
  "post_type": "thread или single message",
  "status": "sent или failed"
}
```

## 🎯 Оркестратор (Orchestrator)

**Роль:** Управление потоком между агентами

### Что может делать:
- ✅ Координировать работу всех 5 агентов
- ✅ Запускать полный цикл обработки
- ✅ Сохранять состояние каждой задачи
- ✅ Загружать предыдущие результаты
- ✅ Отправлять результаты в Telegram по команде
- ✅ Вести историю всех обработанных задач
- ✅ Логировать каждый этап обработки

### Поток обработки:
```
Задача
  ↓
📊 Исследователь (собирает информацию)
  ↓
✍️ Копирайтер (пишет контент)
  ↓
🎨 Дизайнер (генерирует изображение через DALL-E 3)
  ↓
📱 Telegram-агент (готовит сообщение)
  ↓
✅ Редактор (проверяет качество)
  ↓
Сохранение результата + Опциональный постинг в Telegram
```

## 💾 Способы Использования

### 1. Полный Автоматический Цикл
```bash
python run.py
```
- Запускает исследование → написание → дизайн → Telegram-форматирование → проверку качества
- Сохраняет результаты в `outputs/` и `state/`

### 2. Просмотр Доступных Результатов
```bash
python run.py --list
```
- Показывает все обработанные задачи
- Отображает статус каждой
- Показывает, какие уже отправлены в Telegram

### 3. Отправка Конкретного Результата в Telegram
```bash
python run.py --post <task_id>
```
- Отправляет сохранённый результат в Telegram
- Подходит для отложенной публикации
- Можно отправить несколько раз

### 4. Отправка Последнего Результата в Telegram
```bash
python run.py --post-last
```
- Автоматически найдёт последний необработанный результат
- Отправит его в Telegram одной командой

## 🛠️ Конфигурация

### Переменные окружения (.env)
- `ANTHROPIC_API_KEY` — ключ Claude API
- `OPENAI_API_KEY` — ключ OpenAI для DALL-E 3
- `TELEGRAM_BOT_TOKEN` — токен Telegram бота
- `TELEGRAM_CHAT_ID` — ID канала для постинга
- `DALLE_MODEL` — модель DALL-E (dall-e-3)
- `DALLE_SIZE` — размер изображения (1024x1024)
- `DALLE_QUALITY` — качество (standard или hd)

### Параметры агентов (config/agents.yaml)
- Температура (креативность)
- Max tokens (размер ответа)
- System prompts (инструкции агентам)
