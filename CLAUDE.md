# CLAUDE.md

Этот файл содержит рекомендации для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Обзор проекта

Система мультиагентов для создания и распространения контента через различные каналы:

- **Исследователь**: Собирает информацию, проверяет источники, предоставляет проверенный контент
- **Копирайтер**: Преобразует сырые исследования в увлекательный, фирменный контент
- **Дизайнер**: Создаёт визуальные активы и компоненты UI в соответствии с гайдлайнами
- **Telegram-агент**: Управляет взаимодействием с ботом, форматированием сообщений и интеграцией API
- **Финальный редактор**: Проверяет все выходы на качество, консистентность, соответствие и полноту

## Архитектура


## Подготовка к разработке

1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения:
   ```bash
   cp .env.example .env
   # Отредактируйте .env, добавив токен Telegram, API ключи и т.д.
   ```

## Основные команды

- **Запуск оркестратора**: `python orchestrator.py`
- **Запуск тестов**: `pytest` или `pytest -v` для подробного вывода
- **Запуск одного теста**: `pytest tests/test_agent_name.py::test_function_name`
- **Проверка типов**: `mypy .`
- **Линтинг кода**: `flake8 agents/ utils/ tests/`
- **Форматирование кода**: `black .`

## Рабочий процесс агентов

Оркестратор маршрутизирует задачи через агентов последовательно:
1. **Исследователь** → проверяет и собирает информацию
2. **Копирайтер** → создаёт начальный контент
3. **Дизайнер** → генерирует сопровождающие визуалы (если нужны)
4. **Telegram-агент** → форматирует и подготавливает к доставке
5. **Финальный редактор** → проверяет и утверждает перед публикацией

Каждый агент возвращает структурированный вывод (JSON/dict) для передачи на следующий этап. Ошибки на любом этапе останавливают процесс и сообщаются оркестратору.

## Точки интеграции

- **Telegram Bot API**: Настроить `TELEGRAM_BOT_TOKEN` в .env
- **Claude API**: Использует `ANTHROPIC_API_KEY` для всех экземпляров агентов
- **Хранилище**: Выходные данные сохраняются в папку `outputs/` (исключена из git)

## Управление состоянием

Состояние агентов и история разговоров хранятся в `state/` (исключена из git). Оркестратор возобновляет незавершённые процессы при перезагрузке, если файлы состояния существуют.
