🎯 ЭТАП 1: УСТАНОВКА PYTHON
═════════════════════════════════════════════════════════════════════════════

Если Python ещё не установлен:

✓ Вариант 1 - Автоматическая установка (рекомендуется):
  1. Откройте PowerShell в папке проекта
  2. Выполните: powershell -ExecutionPolicy Bypass -File install.ps1
  3. Следуйте инструкциям на экране

✓ Вариант 2 - Ручная установка:
  1. Посетите https://www.python.org/downloads/
  2. Загрузите Python 3.10 или новее
  3. При установке ОБЯЗАТЕЛЬНО отметьте ✅ "Add Python to PATH"
  4. Завершите установку

✓ Вариант 3 - Проверка установки:
  Откройте PowerShell и выполните:
    python --version
  
  Должно вывести что-то вроде: Python 3.11.0

🎯 ЭТАП 3: НАСТРОЙКА API КЛЮЧА
═════════════════════════════════════════════════════════════════════════════

1. Получите API ключ Anthropic:
   - Посетите https://console.anthropic.com/
   - Зарегистрируйтесь или войдите
   - Перейдите в раздел "API Keys"
   - Создайте новый ключ
   - Скопируйте ключ (начинается с "sk-ant-v1-")

2. Откройте файл .env в текстовом редакторе:
   - Используйте VS Code, Notepad++ или обычный Notepad

3. Найдите строку:
   ANTHROPIC_API_KEY=your_anthropic_api_key_here

4. Замените на ваш ключ:
   ANTHROPIC_API_KEY=sk-ant-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

5. Сохраните файл (Ctrl+S)

Пример .env файла:
┌─────────────────────────────────────────────────────────┐
│ # Anthropic API                                         │
│ ANTHROPIC_API_KEY=sk-ant-v1-xxxxxxxxxxxxxxxxxxx...     │
│                                                         │
│ # Telegram Bot (опционально)                           │
│ TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here       │
│ TELEGRAM_CHAT_ID=your_chat_id_here                    │
│                                                         │
│ # Logging                                              │
│ LOG_LEVEL=INFO                                         │
│                                                         │
│ # Storage                                              │
│ STATE_DIR=./state                                      │
│ OUTPUT_DIR=./outputs                                   │
└─────────────────────────────────────────────────────────┘

🐛 РЕШЕНИЕ ПРОБЛЕМ
═════════════════════════════════════════════════════════════════════════════

Проблема: "python: Имя не распознано"
Решение:
  1. Переустановите Python с опцией "Add Python to PATH"
  2. Перезагрузите PowerShell (закройте и откройте заново)
  3. Проверьте: python --version

Проблема: "ModuleNotFoundError: No module named 'anthropic'"
Решение:
  1. Переустановите зависимости:
     pip install -r requirements.txt --upgrade
  2. Или установите отдельно:
     pip install anthropic python-dotenv pyyaml

Проблема: "ANTHROPIC_API_KEY=your_anthropic_api_key_here"
Решение:
  1. Откройте файл .env
  2. Замените текст на реальный ключ из console.anthropic.com
  3. Не добавляйте кавычки вокруг ключа

Проблема: "Connection error" или Claude не отвечает
Решение:
  1. Проверьте интернет соединение
  2. Проверьте, активен ли API ключ в Anthropic Console
  3. Убедитесь, что у вас есть кредиты на аккаунте
  4. Попробуйте ещё раз через 1-2 минуты

Проблема: Процесс длится очень долго
Решение:
  1. Это нормально - обработка может занять 2-5 минут
  2. Claude обрабатывает информацию для каждого агента
  3. Подождите завершения
